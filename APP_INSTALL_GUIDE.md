# 📱 UPI Guard: Mobile & Desktop App Installation Guide

---

## ⚡ Option 1: Phone Par Direct Install Karein (10 Seconds - No APK Needed!)
Google aur Android ka modern standard **PWA (Progressive Web App)** hota hai. Isse ye app bina kisi Play Store ke aapke phone par **Real Native App** ki tarah install ho jati hai:

1. Apne phone ke Chrome browser me app open karein (jaise `http://10.233.200.58:8000/fast_scanner.html` ya hosting link).
2. Chrome ke upar right corner me **3 Dots (⋮)** par click karein.
3. Wahan option aayega:  
   👉 **"Install App"** ya **"Add to Home Screen"** (होम स्क्रीन में जोड़ें)
4. **"Install"** par tap karein!
5. **Boom!** Aapke phone ke home screen par **"UPI Guard"** ka official app icon ban jayega.
   - Jab aap us icon ko dabayenge, toh koi browser URL bar nahi aayegi, ye seedha **as a pure Full-Screen Android App** khulega!

---

## 💻 Option 2: Laptop Par Standalone Windows App Chalayein
Aapke folder me **`UPI_Guard_App.bat`** file bana di gayi hai:
1. Bas **`UPI_Guard_App.bat`** par double click karein.
2. Ye Chrome/Edge ko bina kisi tab, bookmark, ya address bar ke **Dedicated Standalone App Window (450x850 Phone Size)** me khol dega!

---

## 🤖 Option 3: Android Studio me Pure APK Build Karna
Agar aapko hackathon submission me `.apk` file deni hai:
1. Aapke folder me poora Android project ready hai:  
   📂 `fake_upi_detector/android_app/`
2. Android Studio me **"Open Project"** karke is folder ko select karein.
3. Menu me **Build -> Build Bundle(s) / APK(s) -> Build APK(s)** par click karein.
4. 30 seconds me aapka final **`app-debug.apk`** ready ho jayega!
